DSH 视频 / GIF 读取插件 dsh-media-reader 1.0.0

一、适用环境
Windows 10 22H2 及以上或 Windows 11，64 位（x64），DeepSeek Harness 0.2.1-rc.2。
依赖 dsh-plugin-hub 1.0.0，即“方框加号”口袋和“插件配置”基础插件。
当前聊天选中的模型必须支持图片输入。无需额外模型账号，也无需安装 Python、Node、npm 或 FFmpeg。
本包随附抽帧程序、所需 DLL、开源许可证与对应源码资料。安装和本地抽帧可离线完成；模型分析仍使用 DSH 原有的网络与账号配置。

二、安装到本机或另一台机器
1. 把整个 ZIP 复制到目标机器，完整解压；不要在压缩包预览窗口中直接运行安装器。
2. 先在目标机器打开 DSH 一次，让 desktop 配置初始化，然后完全退出 DSH（包括托盘进程）。
3. 如果目标机器尚未安装 dsh-plugin-hub 1.0.0：解压本包 dependencies 文件夹内的 dsh-plugin-hub-1.0.0-win-x64.zip，按它的使用说明运行“安装.cmd”。
   如果已经安装且正常使用，不必重装基础插件。媒体安装器会检查依赖，缺失时停止并给出提示，不会偷偷替换已有基础插件。
4. 回到本包根目录，双击“检查环境.cmd”，确认 DSH 版本、依赖和插件文件齐全。
5. 双击“安装.cmd”，完成后重新打开 DSH。
6. 输入框旁的方框加号应出现“视频 / GIF”；设置侧栏“插件配置”中应出现“视频 / GIF 读取”。

安装器把运行文件复制到目标用户的 <DSH_HOME>\custom-plugins\dsh-media-reader\desktop，再通过 DSH 自带插件命令离线注册。
安装成功后不依赖原 ZIP 解压目录、开发机器的用户名或盘符，可以移动原解压文件夹。
本包不包含任何个人会话、聊天附件、OAuth 凭据、API key 或令牌。OAuth 和 Token 用量仍保留在原来的常用入口。

三、使用方法
1. 打开一个普通聊天会话，选择支持看图的模型。
2. 点输入框旁的方框加号，再点“视频 / GIF”。
3. 选择媒体来源：
   “选择文件”：选择本地视频或原始 GIF。插件强制按原始文件上传，避免 GIF 被普通图片流程变成首帧。
   “聊天附件”：复用当前会话中已经发送的原始视频/GIF文件附件。
   “本地路径”：填写 DSH 所在机器上的媒体路径；读取仍受当前会话的文件访问规则约束。
4. 可以调整均匀抽帧数量、开始/结束秒数，或填写指定时间点，例如 0, 1.5, 3。
   指定时间点会替代均匀抽样。结束时间必须大于开始时间，指定时间点应在片段内且小于结束时间。
5. 填写希望关注的问题，点“加入聊天草稿”。检查草稿及上传状态，再由你发送。
6. 模型调用 read_media 后收到按时间排序的原生图片附件与实际画面时间。
   需要更多细节时，可以继续要求“补抽 3.2、3.8 秒”或“只读取 10 到 15 秒”。

也可以直接在聊天中提供本地媒体路径，要求模型使用 read_media。
复用聊天附件时，工具只接受当前会话中的原始文件附件，不能跨会话用任意附件 ID 读取。
如果 GIF 以前通过普通“图片”流程上传，原文件可能已经只剩首帧。请用本插件“选择文件”重新导入原始 GIF。

四、配置与边界
在“设置 → 插件配置”中搜索 视频、GIF、抽帧 或 media，打开“视频 / GIF 读取”。
默认均匀抽取 12 帧，默认最长边 960 像素；可设置 1–24 帧、640/960/1280/1536 像素。
实际数量和尺寸还会受 DSH 当前部署的图片数量、大小及像素上限约束。
单个原文件最多 512 MB、最长 24 小时；每次最多 24 帧、24 MB 画面。
GIF 按一轮读取，考虑实际帧延时、透明区域和帧处置方式；重复命中同一时间帧时会去重。
抽帧只读取画面，不转写声音。稀疏抽样可能遗漏快速事件，不能把“没有抽到”当成“没有发生”。
抽帧产生的临时原文件和临时图片会在任务结束或取消后清理；已发送的原始附件与输出图片由 DSH 的附件存储管理。
切换会话会关闭导入窗口；已经开始的模型任务可继续在原会话后台运行。取消当前模型任务才会中止对应抽帧，停用插件也会中止进行中的抽帧。
损坏、不支持、受保护或无有效时长的媒体会明确报错。

五、卸载与恢复
完全退出 DSH 后，双击本包“卸载.cmd”，再启动 DSH。
卸载只移除 dsh-media-reader 的注册和运行目录，不移除基础口袋插件，也不改动其他插件配置、会话、凭据和媒体附件。
用户抽帧偏好保存在 <DSH_HOME>\dsh-media-reader.json，卸载时保留，重装后可继续使用。
每次安装/升级/卸载前的事务备份保存在 <DSH_HOME>\backups\dsh-media-reader。
失败时安装器会回滚本次事务；没有联网下载兜底。请保留错误信息和备份位置以便排查。

六、自定义安装位置
默认使用当前用户 .dsh 和 desktop 配置。若使用其他 DSH 安装位置或数据目录，可运行：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\portable.ps1 -Mode Check -DshPath "D:\Apps\DeepSeek Harness" -DshHome "D:\DSH Data" -Profile desktop
把 Check 改成 Install 或 Uninstall 执行相应操作。也可以把这些参数追加到 CMD 启动器后。
目标 DSH 应已正常启动并初始化该配置。Check 为只读检查；安装和卸载期间 DSH 必须完全退出。
